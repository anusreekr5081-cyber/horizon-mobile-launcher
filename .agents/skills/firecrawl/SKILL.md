# Firecrawl Skill

Firecrawl enables crawling entire technical documentation sites, single web pages, and API references, converting them into structured LLM-ready markdown.

## Core Workflows

1. **Clean Markdown Extraction**:
   - Strip navigational chrome, ads, and cookies.
   - Retain semantic code blocks, API tables, and headers.

2. **Recursive Documentation Crawling**:
   - Follow internal documentation links to assemble comprehensive offline reference manuals.
   - Respect rate limits and robot exclusions.
