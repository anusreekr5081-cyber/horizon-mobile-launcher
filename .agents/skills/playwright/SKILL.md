# Playwright Skill

Automate headless Chromium, Firefox, and WebKit browsers for automated UI testing, screenshot comparison, network interception, and rendering verification.

## Core Capabilities

1. **Automated E2E Testing**:
   - Write and execute resilient test suites selecting elements by user-facing roles and text (`getByRole`, `getByText`).
   - Test async page transitions and network responses.

2. **Visual & UI Auditing**:
   - Capture full-page and element screenshots.
   - Verify layout responsiveness across mobile and desktop viewport profiles.
