# Cloudflare Edge & Security Skill

Use this skill when designing, configuring, or debugging Cloudflare Workers, Pages, CDN caching, security rules, and edge APIs.

## Capabilities

1. **Cloudflare Workers & Pages**:
   - Write low-latency edge compute functions in Rust (Wasm) or TypeScript.
   - Configure routing rules, KV stores, R2 bucket storage, and D1 databases.

2. **Edge Security & CDN**:
   - Set up DDoS mitigations, rate limiting, and Bot Management rules.
   - Configure cache keys, stale-while-revalidate headers, and asset optimization.
