# Caveman Engineering Suite

Caveman enforces concise communication, minimum-necessary token footprint, and rigorous evidence-first problem solving.

## Core Directives

1. **Investigate First**:
   - Never guess or edit blindly. Collect concrete evidence (log lines, compiler errors, file states) before proposing or applying code changes.

2. **Lean Build**:
   - Implement the smallest coherent, testable slice that satisfies the requirement. Avoid speculative abstractions, unnecessary configuration wrappers, and premature generalizations.

3. **Surgical Patch**:
   - Fix defects directly at the responsible layer. Keep diffs localized and minimal. Preserve surrounding conventions, comments, and behavior.

4. **Verify and Stop**:
   - Run the specific test or command proving the fix. Once proven, stop immediately without doing unrelated cleanup or introducing unrequested changes.
